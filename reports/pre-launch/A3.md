## Flagged for human review

1. **A3-1 — alt text accuracy is a judgement call.** Every string describes what I saw in the image file, but photo interpretation is subjective and some are stock photos whose intended meaning may differ from their literal content. Worth a skim by someone who knows the brand.
2. **A3-1 — decorative-vs-informative is now consistent, but the boundary itself is a choice.** The site treats section/illustrative photos two ways: several already carry `alt="" aria-hidden="true"` (e.g. `accountants-for-plumbers.astro:130`, `accountants-for-electricians.astro:136`, `hvac-accounting.astro:143`), while their siblings on the same pages carry descriptive alt. **I deliberately did not re-litigate that split** — I only made the *text* accurate, leaving each image's decorative/informative status exactly as the previous a11y pass set it. If the client wants all illustrative section photos treated as decorative, that is a separate, one-line-per-image decision.
3. **A3-3 — the `Service` nodes are deliberately thin.** No `offers`/`price` (pricing is per-quote), no `areaServed` (remote-first, no published service area — inventing one would contradict the deliberate absence of a postal address on the `AccountingService` node). If the client ever publishes a service area, `areaServed` should be added to `ServiceSchema.astro` in one place.
4. **A3-3 — `og:type` is `website` on every page, including all 51 blog posts** (`src/layouts/BaseLayout.astro:87`). `article` would be correct for posts. **Not changed** — it touches the shared layout and belongs with the A2 metadata work rather than being slipped in here. Low risk, ~4 lines.
5. **A3-3 — `BreadcrumbList` was added to blog posts only.** The site renders no visible breadcrumb UI on its flat inner pages; blog posts are the only genuinely two-level path and they do have a trail (the "← Back to Blog" link). Emitting breadcrumbs for one-level pages that show none would be asserting navigation that does not exist. Flagged so the omission reads as a decision, not a miss.
6. **A3-5 — content opportunity, verified against Search Console (see appendix E).** Two edits made, one recommendation left open.
7. **A3-4 — the brand guide has no asset-download section at all.** The checklist anticipates download links (logo files etc.); there are none, so nothing could be broken. Consider adding logo/favicon downloads if the client will ever hand assets to a third party.
