Phase A (repo-only; use `npm run dev` or `npm run preview` for browser checks). Read [PRE-LAUNCH-CHECKLIST.md](../../PRE-LAUNCH-CHECKLIST.md) execution rules first. Enumerate all item IDs before starting; write your ledger to `reports/pre-launch/A3.md`.

Preflight already verified the mechanical layer (alt attributes *exist*, one H1 per page, heading order, JSON-LD parses). This section is the judgment layer on top of it.

| ID | Action | Check | How to Verify | If Failed |
|----|--------|-------|---------------|-----------|
| A3-1 | 🔧⚠️ FIX WITH REVIEW | **Alt text quality** | For every `<img>` in `dist/` (preflight PF-13 guarantees an alt exists), read the alt against the image file and surrounding content. Meaningful images need descriptive alt (what's in the image, not the filename); decorative images need `alt=""`. | Rewrite weak alt text in the source components. Flag all rewrites for human review — accuracy matters more than existence. |

Note: absence is acceptable for thin pages — flag only where content clearly warrants a type. | Add missing JSON-LD blocks derived from actual page content. Where the correct type is ambiguous, flag for human review rather than guessing. |
