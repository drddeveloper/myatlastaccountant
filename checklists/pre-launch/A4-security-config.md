# Section A4 — Security & Configuration 🔒

Phase A (repo-only). Read [PRE-LAUNCH-CHECKLIST.md](../../PRE-LAUNCH-CHECKLIST.md) execution rules first. Enumerate all item IDs before starting; write your ledger to `reports/pre-launch/A4.md`.

> **📄 Reference:** Tier-A checks for every project live in [SECURITY_CHECKS.md](../../SECURITY_CHECKS.md). For payment forms, headless WordPress, SSR + auth, or paid external APIs, also work through [SECURITY_CHECKS_BACKEND.md](../../SECURITY_CHECKS_BACKEND.md). Header/CSP *presence* is preflight-verified (PF-19); this section covers what a script can't judge.

| ID | Action | Check | How to Verify | If Failed |
|----|--------|-------|---------------|-----------|
| A4-1 | 🔧 FIX | **Secrets & env safety** | Run `grep -rn "sk-ant-\|pk_live_\|sk_live_\|whsec_\|password\|secret" src/ --include='*.ts' --include='*.astro' --include='*.js' --include='*.mjs'` — zero hardcoded credentials. Verify `.env` is in `.gitignore`. If `.env.example` exists, it contains only placeholders. | Move secrets to environment variables. Add `.env` to `.gitignore`. If any secret was ever committed, flag for rotation (see A4-4). |
| A4-2 | 🔧 FIX | **Dependency audit** | Run `npm audit`. No high or critical severity findings. Paste the summary as evidence. | `npm audit fix` for auto-fixable issues. For remaining high/critical: update, replace, or document accepted risk — flag for human review. |
| A4-3 | 🔧 FIX | **Exposed files audit** | Confirm none of these are inside `public/` or copied into `dist/` outside build output: `.env`, `.git/`, `SECURITY_CHECKS*.md`, `AI_INSTRUCTIONS.md`, `CLAUDE.md`, `ONBOARDING.md`, `DEPLOY.md`, `checklists/`, `reports/`. (astro-llms-md outputs — `llms.txt`, `llms-full.txt`, per-page `.md` — are intentional and public.) | Remove misplaced files. Note: `reports/pre-launch/` ledgers contain internal audit detail — they must never end up in `public/`. |
| A4-4 | 🔧 FIX | **Git history hygiene** | Run `git log --all --diff-filter=A -- '*.env' '.env.*'` and `git log --all -p -S 'sk-ant-' -S 'pk_live_' -S 'sk_live_'`. Both empty. | Any secret ever committed is compromised — flag for credential rotation. History rewriting (BFG / `git filter-repo`) only if the repo has never been shared. |
| A4-5 | 🔧⚠️ FIX WITH REVIEW | **CSP scope matches reality** | Preflight verified the CSP's baseline directives exist. Judge its *scope*: list every third-party origin the site actually loads (grep `src/` for `https://` in script/iframe/font/connect usage), and compare against the origins allowed in `public/_headers`. Every allowed origin must correspond to a real dependency; every real dependency must be allowed in the right directive (see DEPLOY.md's table). | Remove unused origins; add missing ones to the narrowest directive that works. Flag the diff for review. |
| A4-6 | 🔧⚠️ FIX WITH REVIEW | **Analytics configuration** | `googleAnalyticsId` in `src/data/constants.ts` is either a real GA4 Measurement ID (`G-…`) or intentionally empty (client declined analytics — must be documented). If set, build and confirm the gtag script renders in `dist/index.html` with that ID. | Placeholder or unknown ID → ⏸ BLOCKED; the Measurement ID must come from the team. (Live verification that hits register happens in B2.) |

> **🛑 CHECKPOINT:** Write the ledger, run the verification pass per the runbook. Phase A is now complete — deploy to staging/production, then proceed to B1.
